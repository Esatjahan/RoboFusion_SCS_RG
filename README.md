# Smart Campus Safety & Response Grid (SCS-RG)

An end-to-end IoT-based Smart Campus Safety platform that monitors environmental conditions, performs intelligent risk assessment, stores historical data, and visualizes real-time safety information through an interactive dashboard.

# 📖 Overview

The Smart Campus Safety & Response Grid integrates IoT sensing, backend processing, database storage, and web visualization into a unified monitoring platform.

Sensor data is generated from a simulated ESP32 (Wokwi), securely transmitted to a FastAPI backend, processed using a Risk Fusion Engine, stored in PostgreSQL, and displayed on a React dashboard.

---

# ✨ Key Features

- Multi-sensor environmental monitoring
- Intelligent Risk Fusion Engine
- Real-time React dashboard
- PostgreSQL data storage
- HTTPS communication via Cloudflare Tunnel

- Historical risk visualization

# 🧠 Risk Fusion Engine

The backend combines multiple sensor readings into a single weighted risk score. Emergency override rules ensure that critical situations such as flame detection, severe flooding, and combined smoke-gas hazards are immediately classified as high-risk events.

# ⚙️ Setup

## Backend

```bash
cd backend
pip install -r requirements.txt
fastapi dev app/main.py
```

---

## Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## Database

Create a PostgreSQL database and configure the `DATABASE_URL` inside `.env`.

Run migrations:

```bash
alembic upgrade head
```

---

## Cloudflare Tunnel

```bash
cloudflared tunnel --url http://127.0.0.1:8000
```

Update the generated HTTPS URL inside the ESP32 simulation.
